اتصال وردپرس و ووکامرس به سامانه‌ی امضاگیر؛ داشبورد قراردادها با شورت‌کد و ویجت المنتور، صدور خودکار قرارداد پس از خرید.

== Description ==
* نصب ← فعال‌سازی ← کار می‌کند: اتصال خودکار و امن به سرویس، بدون کلید API و بدون تنظیمات
* ورود یک‌کلیکی به پنل امضاگیر از پیشخوان وردپرس
* شورت‌کدهای [emzagar_dashboard] ، [emzagar_stats] و [emzagar_request_contract]
* ویجت‌های المنتور (دسته‌ی «امضاگیر») با کنترل رنگ و تایپوگرافی
* ووکامرس: قالب قرارداد برای هر محصول، صدور خودکار پس از پرداخت، لینک امضا در صفحه‌ی تشکر/ایمیل و تب «قراردادها» در حساب کاربری
* سازگار با HPOS، RTL و ریسپانسیو

== Installation ==
1. افزونه را از پنل امضاگیر («وردپرس و ووکامرس») دانلود کنید؛ آدرس سرویس داخل آن تنظیم شده است.
2. در وردپرس: افزونه‌ها ← افزودن ← بارگذاری افزونه ← فعال‌سازی.
3. تمام! افزونه خودش وصل می‌شود. (کلید دستی فقط در «تنظیمات پیشرفته» برای سرور اختصاصی است.)

= 2.3.0 =
* خروجی کامل داده‌ها: JSON کامل، CSV هر بخش و بسته‌ی ZIP (بدون اسرار)؛ ورود/بازگردانی با اعتبارسنجی و پشتیبان خودکار پیش از هر به‌روزرسانی.

* محدودیت نرخ: سقف روزانه‌ی صدور از فرم، سقف هر IP و هر ایمیل، تشخیص موج اسپم با قفل خودکار و «قفل اضطراری» یک‌کلیکی (پنل، نوار مدیریت، WP-CLI).
* به‌روزرسانی خودکار افزونه از ابر خودتان (پیش‌فرض: فقط نسخه‌های هم‌خانواده) و نمایش وضعیت لایسنس ابر داخل وردپرس.

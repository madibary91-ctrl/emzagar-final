# افزونه‌ی امضاگیر برای وردپرس

نصب ← فعال‌سازی ← کار می‌کند. افزونه را از پنل امضاگیر (**وردپرس و ووکامرس**) دانلود کنید تا آدرس سرویس داخل آن تنظیم باشد؛ پس از فعال‌سازی خودکار و بی‌صدا وصل می‌شود (بدون کلید API).

جزئیات معماری، امنیت و عیب‌یابی: `docs/WORDPRESS.md` در مخزن اصلی.

- شورت‌کدها: `[emzagar_dashboard]` `[emzagar_stats]` `[emzagar_request_contract]`
- ویجت‌های المنتور (دسته‌ی «امضاگیر») و ادغام کامل ووکامرس
- حالت پیشرفته (سرور اختصاصی): «امضاگیر ← تنظیمات ← تنظیمات پیشرفته»

## همگام‌سازی دوطرفه (نسخه‌ی ۲)

سفارش‌ها و مشتریان ووکامرس به ابر می‌روند و وضعیت امضا لحظه‌ای به سفارش برمی‌گردد (Push امضاشده + Pull + هم‌ترازسازی ساعتی). جزئیات پروتکل: `docs/WOOCOMMERCE-SYNC.md`.

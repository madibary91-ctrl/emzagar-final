# طرح‌های اشتراک پویا (Dynamic Subscription Plans)

پیش‌تر قیمت و سقف طرح‌ها در `src/modules/billing/plans.ts` هاردکد بود. اکنون **منبع حقیقت جدول `subscription_plans`** است
و مدیر کل پلتفرم همه‌چیز را از پنل مدیریت می‌کند؛ بدون تغییر کد و بدون دیپلوی دوباره.

## پنل مدیر کل — `/platform/plans`
| امکان | توضیح |
|---|---|
| ساخت طرح | شناسه‌ی لاتین (ثابت)، نام، توضیح، قیمت ماهانه (تومان)، ویژگی‌های نمایشی (هر خط یک مورد؛ خالی = ساخت خودکار از سقف‌ها) |
| سقف‌ها | قرارداد در ماه و تعداد اعضا (با گزینه‌ی **نامحدود**)، درخواست هوش مصنوعی در ۲۴ ساعت |
| مدت و تخفیف | هر طرح مدت‌های خودش را دارد: `1:0, 3:10, 12:25` یعنی ماهانه، سه‌ماهه با ۱۰٪ و سالانه با ۲۵٪ تخفیف (هر عدد ۱ تا ۶۰ ماه) |
| عمومی/خصوصی | عمومی: در `/pricing`، لندینگ، JSON-LD و پنل خرید دیده می‌شود. خصوصی: فقط با «اختصاص دستی» (و تمدید توسط همان مشترک) |
| پیش‌فرض | طرح پایه‌ی فضاهای بدون اشتراک فعال؛ همیشه دقیقاً یکی، باید رایگان و فعال باشد (ایندکس یکتای جزئی در دیتابیس) |
| طرح پاداش | طرحی که روزهای هدیه‌ی «دعوت از دوستان» روی آن فعال می‌شود (فقط یک طرح) |
| برجسته | نشان «محبوب‌ترین» |
| حذف | بدون سابقه → حذف کامل. با اشتراک/پرداخت → **بایگانی** (فروخته نمی‌شود؛ مشترکان فعلی تا پایان دوره و تاریخچه‌ی پرداخت‌ها سالم می‌مانند). طرح پیش‌فرض حذف نمی‌شود |
| اختصاص دستی | فعال‌سازی هر طرح (حتی خصوصی) برای یک فضای کاری به‌مدت N ماه بدون پرداخت، و لغو اشتراک پولی |

## قواعد رفتاری
- مبلغ پرداخت **همیشه سمت سرور** از روی طرح دیتابیس محاسبه می‌شود (`quotePurchase`)؛ قیمت‌های فرم کلاینت هرگز اعتبار ندارند.
- تغییر قیمت/مدت فقط روی خریدهای بعدی اثر دارد (مبلغ هر پرداخت هنگام شروع ثبت می‌شود)؛ تغییر سقف‌ها فوراً برای همه‌ی مشترکان اعمال می‌شود.
- پرداختِ انجام‌شده برای طرحی که در فاصله‌ی پرداخت بایگانی شد همچنان اشتراک را فعال می‌کند.
- اشتراک منقضی یا طرحِ ناشناخته → طرح پیش‌فرض.
- نصب/ارتقا: جدول با `applySchema` ساخته می‌شود و اگر خالی باشد، سه طرح اولیه (`free`/`pro`/`business` با همان قیمت‌های قبلی) یک‌بار کاشته می‌شود؛ بنابراین اشتراک‌ها و پرداخت‌های موجود بدون مهاجرت دستی ادامه می‌یابند.

## نقشه‌ی کد
- `src/modules/billing/plans.ts` — نوع‌ها، محاسبه‌ی قیمت، اعتبارسنجی ورودی مدیر، داده‌ی اولیه (بدون وابستگی به سرور)
- `src/modules/billing/catalog.ts` — خواندن/ساخت/ویرایش/حذف/پیش‌فرض (دیتابیس)
- `src/modules/billing/purchase.ts` — `quotePurchase`: قابل‌خرید بودن و مبلغ
- `src/modules/billing/plan-actions.ts` — Server Actionهای مدیر کل
- `src/app/platform/plans/page.tsx` — رابط مدیریت
- آزمون‌های جدید: `tests/integration/dynamic-plans.test.ts` و `tests/integration/dynamic-plans-ui.test.ts`

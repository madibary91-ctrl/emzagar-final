# تغییرات UI/UX

## باگ‌های رفع‌شده
- **ریست‌های CSS خارج از لایه‌ی Tailwind بودند** (`a { color: inherit }`، `button { font: inherit }`) و کلاس‌های `text-white`، `text-xs`، `font-bold` را روی لینک و دکمه خنثی می‌کردند؛ برچسب آیتم فعال منو در حالت روشن دیده نمی‌شد. اکنون داخل `@layer base` هستند.
- `select.input` هنگام فوکوس فلش خود را از دست می‌داد (shorthand `background`).
- در حالت تاریک: کاشی `bg-sky-100` سفید می‌ماند و حاشیه‌ی قرمز فیلد نامعتبر دیده نمی‌شد.

## تجربه‌ی کاربری
- جایگزینی `window.confirm` و `window.prompt` با پنجره‌ی دسترس‌پذیر (`components/ui/Modal.tsx`): تله‌ی فوکوس، Esc، قفل اسکرول، بازگشت فوکوس. «رد قرارداد» اکنون فیلد دلیل (اختیاری) دارد.
- صفحه‌های `not-found`، `error`، `global-error` و اسکلت بارگذاری هم‌شکل با پنل برای `admin`، `dashboard`، `support`، `platform`، `account`، `shop` و `contracts/[id]`.
- منوی کناری ۱۹ آیتمی در ۶ گروه؛ کپشن‌ها به tooltip و هدر منتقل شدند.
- حالت خالیِ جدول قراردادها با دکمه‌ی «صدور قرارداد جدید».
- فیلد کد پیامکی: فوکوس خودکار، توضیح پذیرش ارقام فارسی، تایمر ارسال مجدد.

## دسترس‌پذیری
- لینک «پرش به محتوا»، لندمارک `main` یکتا، `aria-current` برای منو و تب‌ها، `role="alert"` و `role="status"` برای پیام‌های فرم.
- منوی موبایل: Esc، تله‌ی فوکوس، قفل اسکرول.
- کنتراست متن‌های کم‌رنگ (`text-ink/30…60`) به حداقل ۴٫۵:۱ رسید؛ کوچک‌ترین متن ۱۱ پیکسل است (قبلاً ۸ تا ۱۰).
- حلقه‌ی فوکوس دولایه (روی پس‌زمینه‌ی روشن و تیره دیده می‌شود).

## موبایل
- فونت فیلدها روی موبایل ۱۶ پیکسل (جلوگیری از زوم خودکار iOS)، دکمه‌ها حداقل ۴۶ پیکسل.
- `themeColor` برای حالت روشن و تاریک و `viewport-fit=cover`.

# داشبورد سلامت سیستم (`/platform/health`)

فقط برای **مدیر کل پلتفرم**. وضعیت زنده‌ی همه‌ی سرویس‌های داخلی و بیرونی را نشان می‌دهد و برای هرکدام ابزار تست و عیب‌یابی دارد.

## سرویس‌های زیر نظر (۲۰ بررسی)
| گروه | بررسی‌ها |
|---|---|
| زیرساخت و امنیت | دیتابیس (تأخیر، نسخه، اتصال‌ها، استخر، جدول‌های ناموجود، تست نوشتن در تراکنش برگردانده‌شده)، سرور/Node، ذخیره‌سازی و دیسک، پیکربندی و امنیت (پرچم‌های خطرناک، شبیه‌ساز، APP_URL)، آدرس عمومی سایت + انقضای TLS، زمان‌بند، بک‌آپ |
| ایمیل و پیامک | SMTP (DNS ← TCP ← بنر ← ورود واقعی بدون ارسال)، پیامک کاوه‌نگار/ملی‌پیامک (اعتبار پنل)، کیفیت تحویل ۲۴ ساعته |
| پرداخت و کیف پول | زرین‌پال، زیبال، آیدی‌پی، پی‌دات‌آی‌آر (دسترسی + TLS + Circuit Breaker + آمار ۷ روز + تست مرچنت بدون پرداخت)، جریان پرداخت (تراکنش معلق، نرخ موفقیت)، تطبیق موجودی کیف پول با دفتر کل |
| هوش مصنوعی | آدرس، احراز هویت (`/models`)، اعتبار مدل، مصرف روزانه، تست تولید متن |
| لایسنس | دسترسی سرور لایسنس، امضای Ed25519، مهلت آفلاین، کانال به‌روزرسانی |
| KYC، دعوت، همگام‌سازی | صف KYC و رمزنگاری، سیستم دعوت (SMTP/APP_URL/IPهای مشکوک)، صف ووکامرس |

## ابزارها
- **بررسی مجدد / تست عمیق** برای هر سرویس (تست عمیق: درخواست آزمایشی به درگاه بدون پرداخت، چند توکن AI، تماس امضاشده‌ی لایسنس، نوشتن در DB، راستی‌آزمایی بک‌آپ).
- **مراحل عیب‌یابی** (DNS ← TCP ← TLS ← HTTP) با زمان هر مرحله و پیام فارسی علت.
- **ایمیل و پیامک آزمایشی** واقعی (با محدودیت نرخ و ثبت در لاگ ممیزی).
- **امتیاز آمادگی لانچ** (۰ تا ۱۰۰) و فهرست «موانع لانچ» با لینک رفع مشکل.
- **تاریخچه**: نمودار تأخیر، درصد دسترسی ۲۴ ساعت/۷ روز، رخدادها (جداول `health_checks` و `health_incidents`، نگهداری ۱۴ روز).
- **هشدار خودکار**: زمان‌بند هر ۱۰ دقیقه همه‌چیز را می‌سنجد؛ قطعی پایدار (≥۵ دقیقه) و بازیابی به مدیران کل ایمیل می‌شود. نشان تعداد رخدادهای باز روی منو.
- **ممیزی متغیرهای محیطی** (فقط تنظیم‌شده/نشده؛ هرگز مقدار).
- **گزارش JSON** برای پشتیبانی: `GET /api/platform/health/export`.
- **پایش بیرونی**: `GET /api/health/status` با `Authorization: Bearer <CRON_SECRET>` ← ۲۰۰ (سالم/کند) یا ۵۰۳ (قطع سرویس حیاتی). `/api/health` ساده برای healthcheck داکر دست‌نخورده است.

## امنیت
فقط مدیر کل؛ درخواست‌های تغییردهنده هم‌مبدأ و JSON؛ محدودیت نرخ؛ هیچ آدرس دلخواهی از ورودی کاربر پیمایش نمی‌شود (SSRF)؛ خطاها از رمز/کلید پاک‌سازی می‌شوند.

## افزودن بررسی جدید
یک `CheckDef` در `src/modules/health/checks-*.ts` بنویسید و به فهرست همان فایل اضافه کنید؛ بقیه (رابط، تاریخچه، هشدار، امتیاز) خودکار است.
